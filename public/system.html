01

ภาพเดินทางอย่างไรHow a picture travels图像怎样传来

คอมพิวเตอร์วิทัศน์ต้องการพิกเซล และเบราว์เซอร์จะยอมให้หน้าเว็บอ่านพิกเซลจากเว็บอื่นก็ต่อเมื่อเว็บนั้นอนุญาต (CORS) เราจึงแบ่งกล้องตามสิ่งที่ทำได้จริง

Computer vision needs pixels, and a browser only lets a page read pixels from another site when that site says so (CORS). So every camera is sorted by what is actually possible:

计算机视觉需要像素。浏览器只有在对方网站允许时，才让一个页面读取另一个网站的像素（CORS）。所以每一台摄像头，都按实际做得到的方式来分：

  • วิดีโอสด สตรีม HLS (รูปแบบมาตรฐานในการส่งวิดีโอสดผ่านอินเทอร์เน็ต) จากโฮสต์ที่ส่ง Access-Control-Allow-Origin: * เบราว์เซอร์ของคุณเล่นและอ่านเฟรมเองโดยตรง เซิร์ฟเวอร์ของเราไม่ได้แตะ
  • ภาพนิ่ง JPEG ที่หน่วยงานเผยแพร่ แต่ไม่มี CORS รีเลย์ของเราดึงภาพมาไว้ในหน่วยความจำแล้วส่งต่อ ไม่เขียนลงดิสก์
  • ดูที่ต้นทาง เจ้าของมีแค่หน้าดูภาพ เราลิงก์ไปได้ แต่ไม่มีเครื่องไหนที่นี่อ่านพิกเซลได้
  • ออฟไลน์ ระบบตรวจสุขภาพของ FloodDash พบว่าสตรีมล่ม
  • Live video — HLS (the standard format for live video on the internet) from a host that sends Access-Control-Allow-Origin: *. Your browser plays it and reads frames itself; our server never touches it.
  • Still — a JPEG the agency publishes without CORS. Our relay fetches it into memory and passes it along. Never written to disk.
  • View at source — the owner only offers a viewer page. We link to it; no machine here can read its pixels.
  • Offline — FloodDash's own health probe found the stream down.
  • 实时视频 — HLS (the standard format for live video on the internet) from a host that sends Access-Control-Allow-Origin: *. Your browser plays it and reads frames itself; our server never touches it.
  • 静图 — a JPEG the agency publishes without CORS. Our relay fetches it into memory and passes it along. Never written to disk.
  • View at source — the owner only offers a viewer page. We link to it; no machine here can read its pixels.
  • 离线 — FloodDash's own health probe found the stream down.

รายชื่อกล้องมาจาก FloodDash ซึ่งรวบรวมกล้องสาธารณะจากเจ็ดแหล่งไว้แล้ว เซิร์ฟเวอร์ของเราอ่านรายชื่อนั้นทุก 10 นาที ถ้าอ่านไม่ได้ก็ใช้ฉบับล่าสุดที่ดีอยู่ แล้วเผยแพร่ที่ /api/cameras รายชื่อมีแค่ชื่อ ตำแหน่ง และประเภทกล้อง ไม่มีภาพ

The list of cameras comes from FloodDash, which already gathers public cameras from seven sources. Our server reads that list every 10 minutes — keeping the last good copy if it cannot — and publishes it at /api/cameras. The list holds names, places and kinds. No pictures.

摄像头列表来自 FloodDash。它已经从七个来源把公共摄像头汇集到一起。我们的服务器每 10 分钟读一次这份列表——读不到时，就保留上一份完好的副本——并把它发布在 /api/cameras。列表里有名称、地点和种类。没有图像。

กล้องหน้าของโทรศัพท์จะแสดงแบบกระจก เพราะคนคุ้นกับหน้าตัวเองแบบนั้น การกลับด้านทำที่ต้นทาง เลนส์และโมเดลทุกตัวจึงเห็นภาพเดียวกับที่คุณเห็น

A front camera is shown as a mirror, because that is how people expect their own face. The flip happens at the source, so every lens and model downstream sees the same picture you do.

前置摄像头显示成镜像，因为人们看自己的脸时，预期的就是这样。翻转发生在源头，所以后面的每一个镜头和模型，看到的图像都和你看到的一样。

ข้อควรรู้ตามตรง: เมื่อคุณดูวิดีโอสด เบราว์เซอร์ของคุณเชื่อมต่อกับเซิร์ฟเวอร์ของเจ้าของกล้องโดยตรง เจ้าของจึงเห็นที่อยู่เครือข่ายของคุณ เหมือนเว็บไซต์ทั่วไปที่คุณเปิด

One honest caveat: when you watch live video, your browser connects straight to the camera owner's server, so that server sees your network address — as any website you open would.

有一句要直说：你看实时视频时，浏览器会直接连到摄像头所有者的服务器。所以那台服务器能看到你的网络地址——你打开任何一个网站，都会这样。

อัตราการขอRate limits速率限制

ภาพนิ่ง: 150 ภาพต่อนาทีต่อผู้เยี่ยมชม ขอติดกันได้สูงสุด 60 ภาพ เกินนั้นได้คำตอบ 429 พร้อมขอให้รอ 20 วินาที เพราะกล้องเป็นของคนอื่น รายชื่อกล้อง: 60 ครั้งต่อนาที ติดกันได้ 20 ครั้ง ตัวนับใช้ที่อยู่เครือข่ายของคุณเป็นกุญแจ อยู่ในหน่วยความจำเท่านั้น และไม่ถูกเขียนลงบันทึก

Stills: 150 a minute per visitor, in bursts of up to 60; beyond that the answer is 429 and a request to wait 20 seconds, because the cameras belong to other people. The camera list: 60 a minute, bursts of 20. The counters are keyed by your network address, held in memory only, and never written to the logs.

静图：每位访客每分钟 150 次，短时间里最多连着 60 次；超出之后，回答是 429，并请等待 20 秒，因为这些摄像头属于别人。摄像头列表：每分钟 60 次，短时间里最多 20 次。计数器用你的网络地址来区分，只放在内存里，从不写入日志。

ทางผ่านThe way in入口

เว็บนี้ให้บริการผ่านอุโมงค์ของ Cloudflare ซึ่งจัดการการเชื่อมต่อของคุณเหมือนผู้ให้บริการเครือข่ายทั่วไป

The site is served through a Cloudflare tunnel, which handles your connection as any network carrier would.

本站通过一条 Cloudflare 隧道来提供。它像任何网络运营商一样，处理你的连接。

นโยบายความปลอดภัยของเนื้อหาContent Security Policy内容安全策略

สคริปต์ สไตล์ ฟอนต์ และโมเดลทั้งหมดมาจากเว็บนี้เอง ไม่มีโค้ดที่ซ่อนอยู่ในตัวหน้าเอง (สคริปต์ในบรรทัด) ไม่มีการสั่งรันโค้ดที่แนบมากับคำขอ (eval) และไม่มีหน้าเว็บอื่นถูกฝังอยู่ในหน้านี้ (iframe) การเชื่อมต่อออกไปข้างนอกที่หน้าเว็บทำได้มีแค่วิดีโอจากโฮสต์ที่รายชื่อเรียกว่า “วิดีโอสด”

Every script, style, font and model is served from here. No code hidden inside the page itself (inline scripts), no running code sent in with a request (eval), and no other web page embedded inside this one (iframes). The only third-party traffic a page may make is camera video, and only to the hosts the catalogue calls “video”.

每一个脚本、样式、字体和模型，都从这里提供。页面里面不藏代码（内联脚本），请求里不夹带要运行的代码（eval），也不把别的网页嵌进这一页（iframe）。一个页面可以发往第三方的，只有摄像头视频，而且只发往目录里称作“video”的那些主机。

  • script-src 'self' · style-src 'self' · font-src 'self'
  • media-src · connect-src: เว็บนี้ และthis site, plus本站，以及 camerai1.iticfoundation.org, camera1.iticfoundation.org, *.ipcamlive.com
  • frame-src 'none' · object-src 'none' · frame-ancestors 'none'
  • Permissions-Policy: camera=(self), microphone=(), geolocation=() กล้องเปิดได้เฉพาะหน้าของเราและเมื่อคุณอนุญาต ไมโครโฟนและตำแหน่งปิดตาย— the camera only for our own pages and only when you allow it; microphone and location are switched off entirely.— 摄像头只用于我们自己的页面，而且只在你允许的时候；麦克风和位置被完全关掉。

สิ่งที่เราตั้งใจไม่สร้างWhat we chose not to build我们选择不建造什么

  1. การจดจำใบหน้าFace recognition人脸识别ระบบนับได้ว่ามี “คน” อยู่ แต่ไม่มีโค้ดส่วนไหนพยายามบอกว่าคนนั้นเป็นใคร เครื่องมือที่ตามหาคนคนหนึ่งข้ามกล้องสาธารณะนับพันตัว ไม่ควรมีไว้ให้ใครก็ได้ใช้It can count that a “person” is there. No code here tries to say who. A tool that finds one person across thousands of public cameras should not be available to anyone who opens a page.它可以数出那里有一个“人”。这里的代码都不去说是谁。一个能在几千台公共摄像头里找出同一个人的工具，不应当交给任何一个打开页面的人。
  2. การอ่านป้ายทะเบียนNumber-plate reading读取车牌ป้ายทะเบียนพาไปถึงตัวเจ้าของรถ เรานับรถได้โดยไม่ต้องรู้ว่าเป็นคันไหนA plate leads to a person. We can count cars without knowing which car is which.一块车牌会通向一个人。我们可以数汽车，而不必知道哪一辆是哪一辆。
  3. การเก็บภาพStoring imagery保存图像ไม่มีคลังภาพ ไม่มีย้อนหลัง ไม่มีชุดข้อมูลที่แอบสะสมไว้ ภาพนิ่งอยู่ในหน่วยความจำ 30 วินาทีแล้วหายไปNo archive, no history, no dataset quietly accumulating. A still lives 30 s in memory and is gone.没有存档，没有历史，也没有一份在悄悄变多的数据集。一张静图在内存里留 30 秒，然后就消失。
  4. บัญชีผู้ใช้Accounts账户ไม่ต้องสมัคร ไม่ต้องเข้าสู่ระบบ ไม่มีรหัสผ่านให้รั่วNothing to sign up for, nothing to log in to, no passwords to leak.没有要注册的，没有要登录的，也没有会泄露出去的密码。
  5. การวิเคราะห์และติดตามผู้ใช้Analytics and tracking分析与跟踪ไม่มีสคริปต์ของบุคคลที่สาม ไม่มีโฆษณา ไม่มีคุกกี้ เราไม่รู้ว่าคุณเป็นใครหรือดูอะไร และอยากให้เป็นแบบนั้นNo third-party scripts, no ads, no cookies. We do not know who you are or what you looked at, and prefer it that way.没有第三方脚本，没有广告，没有 cookie。我们不知道你是谁，也不知道你看了什么，并且希望保持这样。
  6. การประมวลผลบนเซิร์ฟเวอร์Server-side inference在服务器上判断เซิร์ฟเวอร์ไม่เคยดูภาพ มันแค่ส่งต่อบางภาพ การคำนวณทั้งหมดเกิดในเบราว์เซอร์ของคุณThe server never looks at a picture; it only passes some along. Every computation happens in your browser.服务器从不看一幅图像；它只把其中一些传过去。每一次计算都发生在你的浏览器里。
