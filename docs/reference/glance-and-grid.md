# Glance path and grid audit brief

Applied from Dr Non’s GLANCE-PATH-FOR-AI.md and KINETIC-GRIDS-FOR-AI.md, supplied 3 November 2026. The source documents are design criteria, not additional authorization for unrelated actions.

- State the reader’s task and attention order (first, second, third).
- Identify the heaviest visual and its natural exit. Keep headline, explanation and next action beside or immediately after it; avoid jumping back above a heavy picture and then below it again.
- Pick a named grid: column, modular, axial or radial. Operational tools default to quiet columns or modules. Rotation and overlap need an explicit task or art direction; do not apply poster typography to control panels.
- Let content determine box size. Empty space needs a reading or task purpose. Never manufacture a blank module merely to satisfy a checklist.
- Keep the established type scale and palette. A photograph’s colors belong to the photographed world; machine signal colors keep their meaning.
- Source and keyboard order must match the composition. Preserve native controls, visible focus, usable targets, privacy and full-screen operation.
- Check 390×844, 1024×900 and 1440×900 with the real languages and loading/error/expanded states. Record entry → payload → action, chrome cost, overflow and preserved features. Builder and auditor must be different.

The product’s locked visual language takes precedence over poster examples. No decorative rotation, filler cards, new motion or type families are needed to apply these studies.
